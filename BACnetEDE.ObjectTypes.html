    BACnetEDE.ObjectTypes (bacnet_ede v0.1.1)

    Copy Markdown View Source

    The Object Types contain a number of rows or data, identified by its reference number, listing an enumeration of BACnet object types. BACnet object types are defined by the ASHRAE 135 BACnet protocol standard.

    The library bacstack contains BACnet protocol enumerations, so if you already use a BACnet library, you do not need to parse object types files, because the object types are standardized in the BACnet protocol. Only proprietary object types are not standardized (which no one should ever use).

    t()

    @type t() :: %BACnetEDE.ObjectTypes{
  object_types: %{optional(non_neg_integer()) => String.t()}
}

    Object Types are keyed by the BACnet protocol enumeration number to the text as specified in the EDE data (something like "Analog Input").

    The text is though transformed from underscored to a space separated title case. For example analog_input is changed to Analog Input, analog output to Analog Output. But no further modifications are done.
